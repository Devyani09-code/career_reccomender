# Career Recommender System
This platform assists students in identifying suitable academic tracks or professional careers. It uses Machine Learning, Psychometric Analysis, and Streamlit to achieve this. Often, students select a course of study based only on assumptions, the influence of friends, or just their grades. This project seeks to correct that by combining a student's academic results, personal interests, psychological traits, and current job market demand into one evaluation. It then provides a data-supported suggestion instead of an unclear idea.

## What Problem It Solves
Most students pick an academic area without a clear method to check if it matches their personality or natural ability. Career guidance often provides general advice, fitting everyone, and does not consider how a student thinks or acts. This system fills that void with a structured assessment. It brings together academic performance, interests, and personality into a single, custom score, so choices are based on evidence rather than assumptions.

## How It Works
The recommendation score comes from four main parts:
* Academic contribution, which includes performance-based data
* Interest match percentage, showing how well a student's stated interests align with a particular field
* Personality analysis, which comes from the RIASEC model and covers behavioral patterns and preferences
* AI confidence score, which is generated by the machine learning models used

The psychometric layer uses RIASEC personality traits, along with interest and behavior information, to determine suitability before creating the final output.

## What I Learned
This project made me do more than just write code I had to figure out how to turn abstract ideas like "personality" and "interest" into numbers that a computer model could use. Working with Logistic Regression and Naive Bayes together showed me how differently two models can interpret the same data, and why choosing the right one is important. I also got practical experience with the entire process, which included cleaning and analyzing data with pandas and numpy, visualizing trends with matplotlib, and then connecting everything into a functional Streamlit interface supported by a real database (Supabase). Beyond the technical skills, being part of a three-person team taught me how to divide a complex, multi-part project into sections that still combine to form a single, cohesive product.
